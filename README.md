# Hour 0-1: Home page

## Next.js Supabase SSR Setup

1. Copy `.env.local.example` to `.env.local`.
2. Set:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `/login` for auth and `/dashboard` for protected page.
